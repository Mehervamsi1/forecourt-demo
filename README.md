# Forecourt (demo)

Picture survey compliance for every site: a live dashboard, a survey timeline, and one-tap WhatsApp follow-up to site managers.

This repository hosts the **interactive demo** only. All sites, managers and phone numbers are examples. No real data, no backend, no real sign-in.

## Demo accounts

| User ID | Passcode | Role |
|---|---|---|
| `owner` | `owner2026` | Owner: dashboard, sites, messages, setup and costs |
| `admin` | `admin2026` | Super user: everything, plus Users |

## Install on iPhone

1. Open the site in **Safari**.
2. Tap **Share**, then **Add to Home Screen**.
3. Open **Forecourt** from the Home Screen. It runs full screen like an app.

## Deploy

Static files only (`index.html`, `manifest.webmanifest`, `icons/`). Works on GitHub Pages or Cloudflare Pages with no build step.
